NEXUS EIGHT · CELL8 REV-A

An 8-bit console built for games, tools and experiments.

NEX8 is the next-generation direction of NESClone: a C++23 host runtime, native CELL8 cartridge format, emulator, developer tools, RAMSQL dataset layer and an expanding library of games.

SYSTEM

The NEX8 console profile

8-bit PPEGeneral-purpose CELL8 processor with 16-bit addressing and an experimental 8–16 MHz target.
Specialized SPUsParallel 8-bit workers for audio, sprites, physics, AI, collision and other game workloads.
Tile/Sprite GPUIndexed graphics profile targeting a 256×240 display, tile maps, sprites, scrolling and palette RAM.
Cartridge SystemN8CR native cartridges separate program, graphics, audio and data sections from legacy .nes images.
RAMSQLRAM-resident relational datasets with SQL-like operations and the binary N8DB format.
Developer StudioAssembler, linker, emulator, debugger, graphics, audio and project-studio tooling are being built around the core runtime.
